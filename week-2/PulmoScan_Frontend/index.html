PulmoScan is a demonstration interface for a transfer-learning model that screens chest radiographs and flags likely pneumonia cases for a radiologist's review. Built for Week 2 — Designing an AI Model Architecture, it pairs a ResNet-18 backbone with a lightweight classification head trained to prioritize recall over raw accuracy.

Model architecture

A ResNet-18 backbone, pretrained on ImageNet and fine-tuned on chest X-rays, forms the core of the pipeline below.

  1. 1

    X-Ray Input

    Raw chest radiograph, JPG/PNG or DICOM-derived image.

  2. 2

    Preprocessing

    Resize to 224×224 and normalize to ImageNet channel statistics.

  3. 3

    Data Augmentation

    Random flips, rotation, and brightness jitter — training only.

  4. 4

    ResNet-18

    Pretrained residual CNN backbone, fine-tuned on radiographs.

  5. 5

    Global Avg Pooling

    Condenses final feature maps into a single feature vector.

  6. 6

    Fully Connected Layer

    Learns task-specific combinations of pooled features.

  7. 7

    Normal / Pneumonia

    Sigmoid output — a single calibrated probability score.

Design details

How the pipeline handles data, why it's built this way, and where it goes next.

Data Preprocessing

Every chest X-ray is resized to 224×224 and normalized against ImageNet channel statistics so it matches what ResNet-18 expects. Grayscale radiographs are replicated across three channels to fit the network's input shape, and a stratified split keeps the Normal-to-Pneumonia ratio consistent across training, validation, and test sets.

Algorithms

The model fine-tunes ResNet-18's residual blocks, pools the final feature maps with global average pooling, and passes them through a fully connected layer trained with binary cross-entropy and the Adam optimizer.

Benefits

  • Trains effectively on a modest imaging dataset by reusing pretrained features.
  • Outputs a probability, not just a label, so confidence is visible.
  • Light enough to run near real-time on standard hardware.

Challenges

  • Different hospitals' equipment can shift image statistics over time.
  • Small datasets risk overfitting without augmentation and dropout.
  • A missed case is costlier than a false alarm, so thresholds favor recall.

Future Scalability

The output layer can grow from binary to multi-class — separating bacterial and viral pneumonia from normal scans — with no change to the backbone. A Grad-CAM overlay could show clinicians which regions drove a prediction, and the trained model can export to TorchScript or ONNX to serve real predictions through the same API this interface is already structured to call.
