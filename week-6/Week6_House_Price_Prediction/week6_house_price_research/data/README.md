The real California Housing dataset is fetched automatically via
`sklearn.datasets.fetch_california_housing()` and cached here as
`california_housing.csv` whenever internet access is available.

If no internet access is available, `main.py` automatically uses a
schema-matched synthetic fallback dataset generated by
`src/data_loader.py` (clearly labelled as synthetic in all outputs).

To supply your own copy of the real dataset directly, place a CSV with
columns: MedInc, HouseAge, AveRooms, AveBedrms, Population, AveOccup,
Latitude, Longitude, MedHouseVal at this path as `california_housing.csv`.
